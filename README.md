# AI先行者 GEO 运营中台

这是一个可本地运行的 CRM + GEO 全栈后台。CRM 客户管理通过“小人”入口选择 GEO 产品，带入客户身份后进入 AI先行者全域 AI 搜索工作台。

## 在线演示

[https://yanruwill-dot.github.io/ai-pioneer-geo/](https://yanruwill-dot.github.io/ai-pioneer-geo/)

GitHub Pages 版本使用浏览器本地数据层，因此登录、客户切换、新建、筛选、状态流转和配置保存均可操作，刷新后仍可回查。演示数据只保存在访问者自己的浏览器，不会写入生产系统。

## 已实现

- 本地账号登录与会话鉴权
- CRM 客户列表、新建客户和客户上下文切换
- CRM 顶部、引导横幅和每个客户行均提供醒目的“进入 GEO”入口
- GEO 首页：五步营销指引、企业认证、套餐资源和数据概览
- GEO 数据驾驶舱：收录、搜索词、平台、直接转化曝光等按采样明细自动派生的指标
- 可追溯效果指标：AI 提及率、被引用概率、全样本引用率、基线周期对比、平台拆解和拓展词出现场景
- 关键词营销定位、企业知识库、发布任务的新增和持久化
- 自动化任务启停
- AI 搜索营销报表、平台对比、采样明细
- 实名认证与 AI 智能体配置保存
- 转化目标、媒体授权、提示词、批量创作、文章与视频工作流
- 深层页面状态筛选、新建、详情查看和状态流转
- AI 搜索竞争力分析报告
- 响应式桌面与移动端布局
- SQLite 本地数据库、API 集成测试、生产构建

## 启动

```bash
npm install
npm run dev
```

浏览器打开 `http://127.0.0.1:5173`。本地演示账号沿用本次交付约定：

- 账号：`yanru`
- 密码：`123456`

源码中只保存该密码的 scrypt 哈希，不保存明文密码。正式部署时应接入企业 SSO、短信登录或独立账号初始化流程。

## 数据边界

当前版本是独立可运行系统，没有接入对标站生产数据库，也不会修改其客户数据。驾驶舱和深层页面的首批记录来自本地种子数据，新增客户、关键词、知识、配置和业务记录会写入 `data/geo.sqlite`。真实大模型采样、内容生成和对外媒体发布仍需接入对应服务商凭证与平台授权。

### 效果指标口径

- **AI 提及率** = AI 回答明确提及品牌的采样数 ÷ 全部采样数。
- **被引用概率** = 在已提及品牌的采样中出现官网、链接或可验证信源的采样数 ÷ 已提及采样数。
- **全样本引用率** = 出现直接引用或转化目标的采样数 ÷ 全部采样数。
- **基线对比**按采样日期自动拆分为前半段基线周期与后半段当前周期，页面展示“从多少到多少”和百分点变化，不写死增长数字。
- **拓展词场景**根据关键词分类聚合为需求检索、问题求解、行业比较和本地决策，并可回查到每个问题词的平台样本。

外部采样器或平台回查程序可以通过 `POST /api/observations` 写入平台、问题词、排名、提及、引用、情感和采样时间；接口会强制把“未提及但被引用”的矛盾记录归零，避免概率超过 100%。当前仓库内置数据用于演示和回归测试，接入真实平台采样后，驾驶舱会按同一口径实时重算。

GitHub Pages 是静态演示部署，不运行 Express/SQLite 服务；它通过 `src/demoApi.js` 在浏览器本地模拟相同业务接口，并按客户分开保存工作区数据。需要多人共享数据库、账号级权限或真实发布时，应部署完整 Node.js 服务。
